###### IaaS (Infrastructure as a Service)


- IaaS is the delivery of technology

- Basically, you rent hardware or
close-to-hardware


- Used by technical IT and server admins


### Cloud Service Model

###### PaaS (Platform as a Service)


- PaaS provides all of the facilities
required to support the complete life
cycle of building and delivering web
applications and services entirely from
the internet.


- Basically, you rent a VM or environment
services


- Used by developers


- ! Most relevant for our assignments !


### Cloud Service Model

###### SaaS (Software as a Service)


- SaaS is a software delivery methodology
that provides licensed multi-tenant
access to software and its functions.


- Basically, online tools and products like
Google Docs, Blackboard and Netflix


- Used by normies, business users,
consumers, etc.

### Cloud Deployment Models


- Public cloud

     - A type of hosting which cloud services are
delivered over a network for public use.

     - E.g., AWS, GCP, MS Azure


- Private cloud

     - Cloud infrastructure solely used by one
organization.

     - E.g., NTNU’s SkyHigh or a home server


- Hybrid cloud

     - Uses both private and public clouds but can
remain separate entities.


### Cloud Deployment Models


- Public clouds are owned by a company/
organization, and you rent server space


Pros


- Cheap: No large up-front costs, lower economic risk


- Bigger resource pool, scalability


- Less management and responsibility


Cons


- Lack of control: Must trust Amazon, Google, etc.


- Can be more expensive in the long run


### Cloud Deployment Models


- Private clouds are your own servers,
within your own networks


Pros


- More control and flexibility


- Better security: You don’t have trust anybody


- Can be cheaper in the long run


Cons


- High up-front costs


- Higher infrastructure complexity and more management


### Cloud Deployment Models


- Hybrid clouds are a combination
between public and private


Pros


- The best of both worlds


- Security, flexibility + big resource pool where necessary


Cons


- Higher system complexity

## Distributed computing - Transparency


|Transparency|Description|
|---|---|
|Access|Hide differences in data representation and how an object is accessed|
|Location|Hide where an object is located|
|Relocation|Hide that an object may be moved to another location while_in use_|
|Migration|Hide that an object may move to another location|
|Replication|Hide that an object is replicated|
|Concurrency|Hide that an object may be shared by several independent users|
|Failure|Hide the failure and recovery of an object|
