Above, we can see a series of function calls to the Python function move_updater. We give it a list
of moves (a move being a string). For example ["R", "U2"]. Some moves are tagged with a
modifier: Either ' or 2. These modify the move in the following ways:

If a move has a 2 after (e.g., R2 ), it means we want 2 of this move (e.g., ["R", "R"]).
If a move has a ' after it (e.g., R' ), it means we want 3 of this move (e.g., ["R", "R", "R"]).

The function should receive the a list of moves (including modified moves), and return the
unpacked list. Again, see examples above.
